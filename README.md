## Description
A beginner-friendly Python project that simulates basic ATM operations like balance checking, money deposit, and withdrawal using Python fundamentals.

- Check Balance
- Deposit Money
- Withdraw Money
- Exit System

- Data Types
- Input/Output
- Conditions
- Loops
- Type Conversion

## Technologies Used
- Python
